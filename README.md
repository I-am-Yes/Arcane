## Arcane
A custom LibGDX framework inspired by Mindustry/Arc.

## What is this project?
This is a learning project to create a framework for [Main game](https://github.com/I-am-Yes/2d-factory-game-exterLibGDX)

Still in the early stage of development.

## How to use
Not recommended for anyone to use, but if you do, just clone it and open it in JetBrains IntelliJ. (No additional steps required)
